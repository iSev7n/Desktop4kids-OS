# Code of Conduct

## Our Pledge

We pledge to make participation in this project a respectful, welcoming experience for everyone.

Desktop4Kids OS exists to support kids, parents, and educators. We expect the same level of respect and responsibility in this community.

## Our Standards

Positive behavior includes:
- Respectful and constructive communication
- Helpful feedback
- Patience with learners and new contributors
- Prioritizing safety and child-friendly design

Unacceptable behavior includes:
- Harassment or discrimination
- Personal attacks or trolling
- Sharing private information without consent
- Encouraging unsafe behavior
- Sexual, violent, or inappropriate content

## Scope

This Code of Conduct applies within all project spaces, including:
- GitHub Issues
- Pull Requests
- Discussions

## Enforcement

Project maintainers may take action including warnings, comment removal, or bans if behavior violates this Code of Conduct.

## Reporting

If you experience unacceptable behavior:
- Use GitHub’s reporting tools, or
- Open an issue titled **[CoC] Request for Maintainer Contact** (without sensitive details)
